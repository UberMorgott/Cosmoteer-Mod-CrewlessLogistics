Crewless Logistics (BETA 0.4)
[h1]Crewless Logistics - BETA 0.4[/h1]
[b]This is a test build.[/b] It may contain bugs and its parts may still change. For normal play use the stable [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3827751334]Crewless Logistics[/url] item.

[h2]Do NOT subscribe together with the stable item[/h2]
Both items have the same mod ID. Unsubscribe from the stable Crewless Logistics before subscribing to this beta, and back again when you are done testing.

[h2]Requires Yet Another Mod Loader[/h2]
The conveyor belts run in a C# library, which needs [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3577650065]Yet Another Mod Loader[/url] (3577650065).
[olist]
[*]Subscribe to [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3577650065]Yet Another Mod Loader[/url] and wait for the download.
[*]Close the game. Open the loader's Workshop folder [b]<Steam>\steamapps\workshop\content\799600\3577650065[/b] and run [b]Installer.bat[/b].
[*]Start the game, enable Crewless Logistics in the Mods list and [b]trust its library (DLL)[/b] when asked. Restart the game.
[*]After every update of this beta, trust the library again.
[/olist]

[h2]What is new in 0.4[/h2]
Everything from the stable version (crewless electrical network) plus resource logistics in the [b]Storage[/b] and [b]Power[/b] tabs:
[list]
[*][b]Conveyor belt[/b]: two lanes, crew can walk on it, curves automatically and accepts side-loading.
[*][b]Connector[/b]: directional; moves resources between a room, a belt or another room. Filter: Auto by default (passes the only resource both sides can use), Any, one chosen resource or None.
[*][b]Splitter[/b] (1x2): splits one belt into two outputs.
[/list]

[h2]Multiplayer[/h2]
All players need the same beta version, the same loader and the same game version.
